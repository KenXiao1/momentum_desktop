#### 技术实现细节

##### ScheduleTimerManager 类
```typescript
// 核心功能
- addTimer(chainId: string, chainName: string, expiresAt: Date, onExpired?: () => void)
- removeTimer(chainId: string)
- getRemainingTime(chainId: string): number
- formatRemainingTime(chainId: string): string
- isAlmostExpired(chainId: string): boolean
- isExpired(chainId: string): boolean
```

##### 通知时机
- **3分钟警告**: 剩余时间 ≤ 180秒时触发
- **过期通知**: 剩余时间 ≤ 0秒时触发
- **检查频率**: 每10秒检查一次所有预约状态

##### 通知行为
- 3分钟警告: 需要用户交互，不会自动消失
- 过期通知: 需要用户交互，不会自动消失
- 点击通知会聚焦到应用窗口

#### 数据流程

```
创建预约 → 添加到ScheduleTimerManager → 开始倒计时监控
    ↓
剩余时间检查 (每10秒)
    ↓
≤3分钟 → 发送3分钟警告
≤0分钟 → 发送过期通知 → 触发辅助判断
>3分钟 → 继续监控
```

## 合并注意事项

### 1. 依赖关系
- 依赖现有的 `NotificationManager` 类
- 需要浏览器 Notification API 支持
- 与预约系统紧密集成

### 2. 兼容性考虑
- 功能完全基于web标准API
- 不依赖Electron特定功能
- 可直接用于web版本

### 3. 配置要求
- 需要用户授权桌面通知权限
- 依赖应用内通知设置开关
- 基于系统时间进行计时

### 4. 性能影响
- 每10秒执行一次检查循环
- 内存占用极小（仅存储活跃预约）
- 无网络依赖，纯本地计算
