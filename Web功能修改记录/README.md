# Web功能修改记录

## 文件夹目的

因本分支为桌面fork，此处记录涉及到web功能的修改，供未来合并主分支参考。

## 背景说明

本项目的主分支是纯web应用，而当前分支是桌面版本的fork。在开发过程中，我们对核心web功能进行了一些修改和增强。为了便于未来将这些改动合并回主分支时能够准确识别和剥离相关功能，我们在此文件夹中详细记录了所有涉及web核心功能的修改。

## 文档结构

每个功能模块的修改记录都包含以下信息：
- **文件变更**: 涉及的具体文件和修改内容
- **功能描述**: 新增或修改的功能特性
- **技术实现**: 关键的代码实现和架构设计
- **合并注意事项**: 未来合并时需要特别关注的要点

## 使用说明

1. **开发阶段**: 当对web核心功能进行修改时，请及时更新相应的记录文档
2. **合并准备**: 在准备合并主分支前，请仔细阅读相关文档，了解需要剥离的功能
3. **功能剥离**: 根据文档中的详细记录，准确识别和移除桌面特有的功能
4. **测试验证**: 剥离后请确保web应用的核心功能正常运行

## 维护原则

- **及时更新**: 每次涉及web功能的重要修改都应该记录
- **详细准确**: 记录应包含足够的细节以便未来参考
- **分类清晰**: 不同功能模块应分别记录，便于管理
- **版本追踪**: 记录具体的git提交信息，便于版本控制
